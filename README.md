# MyEstahban City

My Estahban is a smart companion for city services in Estahban.

## Features
- Smart product scanner
- Cart management & order history
- Secure authentication system
- Modern and responsive UI
- Offline support capabilities

## Getting Started
To get started with this project, ensure you have the Flutter SDK installed.

1. Clone the repo: `git clone https://github.com/DataistOS/my_estahban_city`
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`
